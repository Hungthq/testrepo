# 🖍️ Draw & Learn

A drawing and learning app for kids. It runs in any web browser on a tablet, phone or computer, with no install and no internet needed.

## How to open it

- **Quickest:** double-click `index.html`.
- **On a tablet or phone:** run `npx serve draw-and-learn` and open the address it prints from a device on the same Wi-Fi. You can also host the folder on GitHub Pages, Netlify or Vercel. Then use your browser's "Add to Home Screen" so it opens like an app.

## What kids can do

| Mode | What happens |
|------|--------------|
| 🎨 **Draw** | Free drawing with 9 colors, 3 brush sizes, a 🌈 rainbow brush, ⭐ stickers, an eraser, undo and a 🗑️ clear button. Tap a color to hear its name. |
| 🔤 **ABC** | Trace letters A–Z. Each one comes with a picture word ("A is for Apple 🍎") that is read aloud. |
| 🔢 **123** | Trace numbers 0–10, with emoji to count ("3 🐥🐥🐥") and spoken counting. |
| 🔷 **Shapes** | Trace a circle, square, triangle, rectangle, star, heart, diamond and oval. |

In the learning modes, press ✅ when you finish tracing. The app checks how much of the gray guide you covered and how well you stayed on it. Then it gives 1–3 ⭐ and a cheer, or a gentle nudge like "Keep going!".

💾 saves the picture as a PNG. 🔊 turns sound on or off.

## Files

- `index.html`: page layout
- `style.css`: kid-friendly styling, works on phones and tablets
- `app.js`: drawing, lessons, speech, and tracing scores
